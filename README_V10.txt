МЕКТЕПІШІЛІК БАҚЫЛАУ — V10 (тәрбие бөлімі қайта жасалды)

1. index.html файлын Chrome немесе Edge браузерінде ашыңыз.
2. Құпиясөз: Admin (жергілікті кіру экраны; серверлік қорғаныс емес).
3. «Тәрбие процесі» бөлімінде сол жақтағы 13 бағыттың бірін таңдаңыз.
4. Бағыттың ішкі «Бұйрық», «Жоспар», «Тізім», «Анықтама» бөлімдерін таңдаңыз.
5. «Жазба қосу» немесе «PDF жүктеу» арқылы мәлімет енгізіңіз.
6. PDF файлдары IndexedDB-де, жазба мәтіндері localStorage-де сақталады.
7. Басқа компьютерде мәліметтер автоматты түрде көрінбейді: серверлік нұсқа әлі жасалмаған.

V10 түзетулері:
- 13 бағыт ықшам бүйірлік навигациямен қайта жасалды.
- Әр бағыттағы ішкі бөлімдер нақты бөлінді.
- PDF тіркемесі бар жазбаны өңдегенде файлды қайта таңдау міндетті емес.
- Жазба сақтауда екі рет жіберуден қорғау және қате туралы хабарлама қосылды.
- Бұрынғы v9_ кілттеріндегі жазбалар сақталады.

МАҢЫЗДЫ: Алдыңғы сайттағы деректерді сақтап қалу үшін сол браузердегі
бірдей сайт мекенжайын/папкасын пайдаланыңыз; жаңарту алдында JSON резервтік
көшірмесін жасаңыз. Сайтты басқа мекенжайдан ашу IndexedDB деректерін бөлек көрсетеді.
